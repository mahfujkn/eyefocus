# EyeFocus — Privacy Policy & Local Storage Statement

**Effective Date**: August 2026

## 1. Core Principle
EyeFocus is designed from the ground up as a **100% offline, privacy-first Windows desktop utility**.

## 2. No Data Collection
- EyeFocus **does not collect, track, store, or transmit** any personal data, usage analytics, device telemetry, keystrokes, screen contents, or browsing history.
- The application contains **zero third-party SDKs, zero advertising frameworks, and zero analytics libraries**.

## 3. Local-Only Storage
All configuration files, user profiles, and schedules are stored exclusively on your local machine:
- **Settings Path**: `%LocalAppData%\EyeFocus\settings.json`
- **Backup Settings**: `%LocalAppData%\EyeFocus\settings.backup.json`
- **Optional Debug Logs**: `%LocalAppData%\EyeFocus\Logs\` (Only created if explicitly enabled in Settings; logs contain no personal data and can be cleared at any time).

## 4. Zero Network Requirements
EyeFocus performs **no outbound network requests**. Normal operation is completely functional in air-gapped and offline environments.
